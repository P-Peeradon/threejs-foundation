# ThreeJS Foundation

What if you could construct entire interactive 3D cities, simulate real-time floodplains, or manipulate complex mathematical curves directly inside a standard web browser without installing third-party plugins?

Welcome to your 5-day self-study laboratory manual for mastering Three.js and spatial geometry transformations. Operating on a structured schedule of 2 hours per day across 5 targeted laboratory sessions, this manual transforms lower-level WebGL mechanics into intuitive, hands-on programming experiences. By dedicating 10 focused hours, you will progress from basic 3D rendering to building modular web components capable of mathematical curve transformation.

## Laboratory Objective
Upon completing this laboratory manual, you will be able to:
- Construct and render interactive 3D graphics inside an HTML canvas using Three.js primitive elements, materials, and dynamic animation loops.
- Manipulate structural and spatial data by generating custom BufferGeometry structures, vector arrays, and procedural spatial grids.
- Perform geometric matrix transformations ($4 \times 4$ homogeneous affine matrices) on line segments, conic sections, cubic equation curves, and surface normal vectors.
- Develop responsive web components that encapsulate Three.js spatial viewers, manage viewport resizing, and handle resource disposal.
